# Dr. Anirudh Gowda — Arogya Clinic website demo

A small, responsive static website for Dr. Anirudh Gowda, OBGYN, at Arogya Clinic in Mandya. It follows the supplied reference site's warm visual style and scroll-driven rotating white-coat sequence, while using OBGYN-specific information and a new story reader.

## What is included

- A scroll-controlled white-coat rotation on desktop and mobile, with a reduced-motion option.
- Doctor profile, qualifications, education, languages, experience, clinic hours, map, phone and WhatsApp appointment links.
- Draft OBGYN care areas, an online visit description and a privacy note.
- Ten fictional, simple-English OBGYN conversations. Each has a patient-friendly opening, a step-by-step dialogue, related concerns, possible next steps and a separate urgent-help note.
- A review checklist and source list in `DOCTOR-REVIEW.md`.

## Local preview

Open `index.html` in a browser. The site is plain HTML, CSS and JavaScript and has no build step, server, analytics or patient-data form. The conversation examples and hero frames are loaded from the site's own files. Google Fonts are requested from Google Fonts when a visitor is online; the page falls back to system fonts when they are unavailable.

## Appointment links
